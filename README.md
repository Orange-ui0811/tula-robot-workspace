# TULA 机械臂项目资料与开发工作区

本仓库保存迈瑞博 TULA 机械臂项目的硬件资料、SCARA 可视化模型、控制程序源码，以及 WSL2 / Ubuntu / ROS2 / LeRobot 环境配置与已有验证记录。

## 目录

| 路径 | 内容 |
| --- | --- |
| `程序文件/TULA_Robot_Workspace/` | 从交接包提取的 LeRobot 源码快照、独立 TULA 插件、TD-201 C SDK 与交接文档 |
| `程序文件/TULA_Python_Test_Windows/` | Windows 纯 Python 串口调试工具、中文菜单与模拟串口测试 |
| `程序文件/CDM2123620_Setup.exe` | 原始串口驱动安装程序 |
| `TULA驱动器资料/` | TD-201 / TD-102 手册、命令表与厂商工具 |
| `URDF/` | 四轴 SCARA 可视化草稿与五个 STL 部件 |
| `Lerobot/` | LeRobot 介绍和学习资料 |
| `环境配置/` | ROS2 / LeRobot 安装与验证脚本、使用说明及历史日志报告 |
| `资料摘录/硬件/` | 从交接包提取的执行器、转台和控制器规格资料 |
| `交接包来源.json` | 原始程序压缩包哈希、提取规则和逐文件内容哈希 |

## 当前状态

- Windows TULA 插件 0.1.0 对接交接包中的 LeRobot 0.6.2。原始文档记录 13 项无硬件测试通过；纯 Python 工具的文档记录 28 项模拟串口测试通过。
- 已有 ROS2 报告记录节点通信和 RViz 启动验证通过。
- 已有 Linux LeRobot 报告记录小型随机 ACT 的 GPU 训练 / 推理、视频读写、本地数据集读写、PushT 示例仿真和 CLI 入口检查通过。这些是安装验证，不代表已训练出真实机械臂策略。
- TULA 实机通信、运动、停止和周期性能仍需独立验收；Windows `td201.dll` 不能直接在 Linux Python 中加载。
- URDF 明确标为可视化草稿，关节范围和动力学占位值不能作为实际硬件参数。

以上描述来自随附资料；本次 GitHub 归档只整理和校验文件，没有连接设备、执行运动或重新进行软件功能验收。

## 获取仓库

本仓库使用 Git LFS 保存 STL 模型和 LeRobot 原有规则指定的测试资源。克隆前安装 Git LFS，克隆后执行 `git lfs pull` 获取完整二进制内容。

本地环境需要重建，优先阅读 `环境配置/使用说明.txt`、`环境配置/LeRobot使用说明.txt` 和 `程序文件/TULA_Robot_Workspace/lerobot/README.local.md`。交接文档中的绝对路径来自原机器，换机时应按实际目录调整。运行硬件程序前先阅读工作区内的 `硬件测试说明.md`。
