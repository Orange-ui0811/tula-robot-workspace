TULA Windows handoff package v4
Updated: 2026-10-24

v4 变更：
1. 菜单功能 10、11、12 共用的直线轴默认 counts_per_mm 由 10000 改为 50000，输入示例同步更新。
2. 直线轴软件最大行程默认值由 25.0 mm 改为 15.0 mm。
3. start_menu.bat 增加启动环境选择：Conda 环境、指定 python.exe、系统 Python、uv 虚拟环境。
4. Conda 支持输入环境名称，并查找常见安装位置；uv 默认使用项目目录下的 .venv，也可指定其他环境目录。
5. 启动前检查所选环境及 pyserial 依赖；缺少依赖时仅提示手工安装命令，不再自动安装。
6. 每次启动重新选择环境，不保存配置；启动提示使用简短英文，支持中文及含空格的路径。

v3 变更：（2026-10-17）
1. 单轴及双轴运动等待时，仅在同一轴 MOTOR_RUNNING 期间暂时容许 POSITION_ERR。
2. 保留停止后的报警检查、其他错误停机、超时和最终位置容差。
3. 增加 14 项离线回归测试，完整模拟串口测试共 28 项通过；实机运动待验证。
4. Git 原版标签：before-position-err-fix-20261017；修复标签：position-err-fix-20261017。

v2 历史（2026-07-15）：

本版本变更：
1. 删除“列举电脑串口”菜单。
2. 菜单功能重新编号为 1-12。
3. 输入 COM4、COM5、COM15 等端口号时不再扫描串口。
4. 完全取消 tula_windows_config.json，不再写入配置文件。
5. 串口号仅在本次菜单运行期间有效，重新启动后请再次选择功能 1。
